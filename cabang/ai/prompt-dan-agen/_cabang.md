## Ringkasan
Cabang 'ai/prompt-dan-agen' berfokus pada evolusi pemanfaatan kecerdasan buatan dari sekadar perancangan prompt statis menuju penerapan sistem agen otonom yang kompleks dan efisien. Tema besar ini mencakup rekayasa konteks, pengelolaan dokumen panduan keterampilan (SKILL.md), serta integrasi Model Context Protocol (MCP) yang memungkinkan agen mengambil keputusan pemilihan alat secara dinamis saat runtime [[K-0052]]. Peningkatan kapabilitas ini didorong oleh penambahan lapisan struktural seperti harness, loop, dan graph yang mentransformasi model AI menjadi agen fungsional [[K-0050]]. Dalam praktiknya, teknologi ini diimplementasikan melalui otomatisasi alat pengembangan seperti server MCP dan skill SEO open-source [[K-0003]], serta penerapan agen GTM otonom 24/7 yang mampu menjalankan fungsi bisnis strategis seperti pencarian dan penjangkauan klien secara mandiri [[K-0014]], bahkan mendorong pertumbuhan perusahaan SaaS hingga jutaan dolar tanpa staf sales manusia [[K-0013]].

## Poin Kunci
- Penerapan paket skill open-source dan server MCP mengotomasi tugas teknis seperti audit dan ekstraksi transkrip [[K-0003]].
- Otomasi agen AI terbukti mampu menggerakkan pertumbuhan bisnis SaaS hingga $2 juta ARR tanpa staf sales manusia [[K-0013]].
- Agen GTM otonom 24/7 menjalankan proses pencarian dan penjangkauan klien secara mandiri [[K-0014]].
- Lapisan harness, loop, dan graph adalah kunci transisi model AI menjadi agen otonom fungsional [[K-0050]].
- Model Context Protocol (MCP) mengalihkan pemilihan alat ke keputusan runtime agen AI [[K-0052]].
