## Ide
Cara memasang `google-colab-cli` di komputer lokal sangat ringkas: gunakan `uv tool install google-colab-cli` (direkomendasikan agar terisolasi rapi) atau `pip install google-colab-cli`, lalu langsung jalankan perintah eksekusi VM dari terminal.

## Kutipan Pendukung
> uv tool install google-colab-cli
