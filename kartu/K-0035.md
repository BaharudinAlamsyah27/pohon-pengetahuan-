## Ide
1. Anthropic menghadapi tantangan migrasi API pesan dari Python ke Rust karena sistem produksi terus berubah, respons AI yang non-deterministik, serta privasi data pelanggan yang tidak bisa dibaca secara langsung.
2. Untuk membangun kepercayaan, mereka menggunakan API produksi itu sendiri sebagai verifikator untuk menguji versi Rust pada lalu lintas nyata.
3. Agen AI dikerahkan secara otomatis untuk menemukan dan memperbaiki perbedaan antara versi Python dan Rust.
4. Hasilnya, layanan dapat dikirimkan ke produksi dengan penggunaan CPU 70% lebih sedikit per permintaan dan pemotongan waktu respons median sekitar 20% tanpa menghentikan layanan.

## Kutipan Pendukung
