## Ide
1. API bekerja sebagai kontrak tetap yang diprogram manual oleh pengembang, sementara server MCP memaparkan data dan alat agar model AI dapat memilihnya secara dinamis saat berjalan.
2. Sebagian besar server MCP bertindak sebagai lapisan tipis di atas API yang sudah ada untuk menjembatani sistem.
3. Pertukaran utamanya adalah kendali; karena model memutuskan saat runtime, pengelolaan log, izin akses, dan peninjauan menjadi jauh lebih krusial.
