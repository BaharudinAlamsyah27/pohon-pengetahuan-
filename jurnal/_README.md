# Folder Jurnal Pribadi (Khusus Lokal)

Folder ini menyimpan catatan harian penghujung hari dalam format Markdown murni tanpa batas kata:

```
jurnal/
└── YYYY/
    └── MM/
        └── YYYY-MM-DD.md
```

**Aturan Privasi Ketat (Pilihan A):**
- Hanya aktif di **Mode Lokal (`127.0.0.1`)**.
- **Dilarang keras** masuk ke folder `situs/` atau publikasi Vercel.
- Diverifikasi otomatis oleh `periksa_kebocoran.py` sebelum setiap publikasi.
