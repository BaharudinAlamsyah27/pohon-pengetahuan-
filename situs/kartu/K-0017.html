Instalasi google-colab-cli dapat dilakukan dalam satu baris perintah melalui manajer paket uv (uv tool install google-colab-cli) atau pip.

Cara memasang `google-colab-cli` di komputer lokal sangat ringkas: gunakan `uv tool install google-colab-cli` (direkomendasikan agar terisolasi rapi) atau `pip install google-colab-cli`, lalu langsung jalankan perintah eksekusi VM dari terminal.

uv tool install google-colab-cli

Relasi

  • lanjutan-dari K-0016 — Fitur Ephemeral Job Runner (colab run) di google-colab-cli dapat membuat VM baru, menjalankan skrip lokal, mengambil file hasil, dan mematikan runtime otomatis dalam satu perintah.
