Fitur Ephemeral Job Runner (colab run) di google-colab-cli dapat membuat VM baru, menjalankan skrip lokal, mengambil file hasil, dan mematikan runtime otomatis dalam satu perintah.

Mode `colab run` pada `google-colab-cli` bekerja sebagai penjalan tugas sementara (ephemeral job runner): sistem otomatis menyiapkan VM baru di cloud, menjalankan skrip lokal beserta argumennya, mengunduh file keluaran, lalu langsung mematikan runtime agar kuota komputasi tidak terbuang.

Ephemeral Job Runner (colab run): Provision a fresh VM.

Relasi

  • lanjutan-dari K-0015 — Perkakas resmi google-colab-cli memungkinkan developer menyalakan runtime CPU, GPU, dan TPU Google Colab serta menjalankan kode lokal langsung dari terminal.
  • prasyarat-untuk K-0017 — Instalasi google-colab-cli dapat dilakukan dalam satu baris perintah melalui manajer paket uv (uv tool install google-colab-cli) atau pip.
